# 桌面时间组件 · time_budget

部分设备会因刻意修改时区（例如为某些应用进行环境伪装），或系统时间显示组件损坏，导致无法方便、准确地查看所需时区的时间；也有人希望拥有更直观、美观的时间显示。这个轻量桌面组件由此开发。

组件基于系统 UTC 时钟换算时间，默认显示北京时间，不受系统时区设置影响。**它不单独联网校时；如果底层系统时钟本身不准，仍需先校准系统时间。**

## 如何部署在你的本地

1. 在 Windows 上安装 Python 3.11（包含 tkinter），启用 Python 启动器或将 Python 加入 PATH；无需安装第三方依赖。
2. 下载或克隆本项目，双击 `start-clock.cmd` 启动。也可在项目目录打开终端，执行：

   ```powershell
   pythonw .\clock.pyw
   ```

3. 如需开机自启，在项目目录执行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install-autostart.ps1
   ```

   启动脚本会自动定位 Python 和项目目录，无需修改本机路径。移动项目目录后，重新运行自启脚本即可。

取消自启：打开 `shell:startup`，将「真实时间.lnk」移入回收站。修改显示时区：编辑 `clock.pyw` 中的 `OFFSET_HOURS`、`TZ_LABEL`，然后重启组件。

## 具体功能说明

点击右上角 `···` 或右键打开菜单。

| 功能 | 说明 / 操作 |
|---|---|
| 时间显示 | 时分秒、日期、星期、UTC 时间及日进度线 |
| 手动缩放 | 拖动右下角或 Ctrl＋滚轮；默认 192 × 108，宽度可调至 144–480 逻辑像素 |
| 移动与 Pin | 拖动卡片移动；点击图钉锁定或解除位置固定 |
| 显示层级 | 可选始终最上层，或仅桌面层；桌面层可被应用覆盖，Win＋D 后仍可见 |
| 外观主题 | 14 套主题：8 套浅色、3 套彩色、3 套深色，菜单内切换 |
| 自动记忆 | 保存位置、尺寸、Pin、主题与显示层级；支持高 DPI 和多屏位置 |
| 启动与退出 | 支持开机自启、单实例运行；通过菜单退出 |

## 目录下文件说明

| 文件 | 用途 |
|---|---|
| `clock.pyw` | 主程序：界面、交互、时间刷新与设置保存 |
| `clock_settings.py` | 主题、尺寸限制及设置处理 |
| `window_layer.py` | Windows 窗口层级、桌面附着、圆角与多屏定位 |
| `start-clock.cmd` | 无控制台的双击启动脚本 |
| `install-autostart.ps1` | 创建开机自启快捷方式 |
| `tests/` | 设置、位置计算和窗口层级的回归测试 |
| `.gitignore` | 排除运行状态、日志和缓存 |
| `.gitattributes` | 统一文本与 Windows 脚本的换行格式 |
| `state.json` | 自动生成，记录设置和运行状态 |
| `error.log` | 启动异常时生成，供排查问题 |
